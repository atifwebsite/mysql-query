31. Find all salespeople whose name starts with ‘P’ and the fourth character is ‘l’..

32. Write a query that uses a subquery to obtain all orders for the customer named Cisneros. 
Assume you do not know his customer number

select * from orders where orders.cnum = (select customers.cnum from customers where customers.cname = 'Cisneros');

38. Write a select command using a corelated subquery that selects the names and numbers of all 
customers with ratings equal to the maximum for their city.

select cname,cnum from customers as c1 
where rating = (select MAX(rating) from customers as c2 where c1.city = c2.city);

39. Write a query that totals the orders for each day and places the results in descending order. 
select odate,SUM(amt) as total_orders
from orders
group by odate
order by total_orders DESC;

43. Write a query that selects the highest rating in each city.

44. Write a query that calculates the amount of the salesperson’s commission on each order by a 
customer with a rating above 100.00. 

select o.onum,o.amt,c.cname,s.sname,
(o.amt * s.comm) as Commision
from orders as o 
left join customers as c on o.cnum=c.cnum
left join salespeople as s on o.snum = s.snum
where c.rating > 100;

45. Count the customers with ratings above San Jose’s average.
